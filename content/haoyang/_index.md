## 四大工具对比

| 工具 | 类型 | 安装方式 | 内置免费模型 | 免费份额详情 |
|------|------|----------|--------------|--------------|
| **Gemini** | 网页 + CLI | `npm install -g` | ✅ 每日 1000 次 | Google AI Studio 免费层 |
| **OpenCode** | CLI 编码助手 | `npm` / `mise` / `npx` | ✅ 内置 DeepSeek 等 | 无需 API Key，直接使用 |
| **Cline** | VSCode 插件 | VSCode 扩展商店 | ❌ 需自行配置 | 配合 OpenRouter 使用 |
| **OpenRouter** | API 聚合平台 | 网页注册 | ✅ 400+ 免费模型 | `:free` 后缀完全免费 |
