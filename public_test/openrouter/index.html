平台概览

OpenRouter 聚合了来自全球数十家厂商的大语言模型，提供统一的 API 接口与按量计费。用户无需分别接入各厂商平台，即可在单一入口调用 GPT、Claude、Gemini、Qwen 等主流模型。

核心优势

  • 模型聚合：覆盖 OpenAI、Anthropic、Google、阿里、Meta 等厂商的旗舰与轻量模型
  • 智能路由：根据提示词自动选择最优模型，兼顾效果与成本
  • 按量付费：免去订阅费用，仅按实际调用 token 数计费
  • 无缝切换：同一 API 格式即可切换任意模型，无需修改代码
